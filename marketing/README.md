# Marketing kit — Trophée du renoncement

Vector artwork (SVG) for shirts, stickers and anything else. Colors are the
site palette: sky `#2b7bbf`, deep `#1d5e96`, light accent `#8ec5ef`, white.

| File | Use | Size as drawn |
|---|---|---|
| `logo.svg` | The emblem alone (any use) | scalable, square |
| `sticker-round.svg` | Die-cut round sticker | 70 mm doc = **64 mm cut + 3 mm bleed** |
| `tshirt-front-crest.svg` | Chest print, transparent background | ~100 × 130 mm |
| `tshirt-back-dark-fabric.svg` | Back print, white text (navy/black shirt) | ~280 mm wide |
| `tshirt-back-light-fabric.svg` | Back print, blue text (white/grey shirt) | ~280 mm wide |

## Typeface

**Montserrat Bold** (SIL Open Font License, on Google Fonts) — geometric sans
inspired by mid-century signage; install it locally if you edit the source
files. The `print/` files need no font at all: their text is outlined.

## Sending to a print shop

1. **Use the `print/` versions** — text is already converted to paths
   (Montserrat Bold outlines), so they render identically everywhere. No
   Inkscape step needed. The top-level files are the editable sources.
2. **Export what the shop asks for**: most accept SVG/PDF as-is; for PNG,
   export at 300 dpi minimum (Inkscape: File → Export, set DPI).
3. **Stickers**: the round file already includes 3 mm bleed — tell the shop
   "70 mm document, 64 mm cut circle". Matte lamination survives glove
   handling and cold takeoffs better than gloss.
4. **Shirts**: front crest and back prints have transparent backgrounds. The
   crest works on any fabric; pick the back variant matching the fabric.
   Screen printing wants ≤ 3 colors — these designs use exactly 3 + white.
